Phishing Email Investigation
Second phishing email investigation focused on email header analysis, IOC extraction, malware analysis, and threat intelligence.
Investigation Overview
This investigation analyzes a suspicious phishing email and documents the techniques used to identify indicators of compromise (IOCs), examine the sender infrastructure, and assess potential malicious activity.
The investigation was performed in a controlled environment using publicly available security analysis tools.
Investigation Objectives
Analyze the suspicious email and sender information
Examine email headers and identify suspicious indicators
Investigate the sender domain and IP information
Extract and analyze potential IOCs
Analyze encoded content using CyberChef
Identify potential malware or malicious behavior
Document findings and investigation evidence
Tools Used
CyberChef
WHOIS / Domain Intelligence
IP reputation and abuse databases
Threat intelligence services
Email header analysis tools
Investigation Process
Email and sender analysis
Email header analysis
Domain investigation
IP address investigation
IOC extraction
Base64 decoding and analysis
Malware analysis
Threat intelligence correlation
Final assessment
Key Findings
The investigation identified several suspicious indicators associated with the email.
Further analysis of the encoded content revealed content associated with cryptocurrency mining activity.
The investigation findings, screenshots, and supporting evidence are stored in the evidence directory.

Conclusion
The email showed characteristics consistent with a phishing attempt and contained indicators requiring further security investigation.
The investigation demonstrates a basic SOC workflow for analyzing suspicious emails, extracting IOCs, investigating infrastructure, and documenting findings.
Disclaimer
This investigation was performed for cybersecurity learning and defensive security practice. All analysis was conducted in a controlled environment.
